**This is a fork.** The original app is [Oscar°](https://oscarweather.app) by Philipp Bolte — see
[oscarweather.app](https://oscarweather.app) and [strumswell/oscar-weather](https://github.com/strumswell/oscar-weather).
If you just want the app, go there.

I forked it because I wanted a simplified UI and a calmer experience: a standard iOS look, native
controls, no in-app purchases and none of the playful extras — while keeping the forecasts, radar,
maps, widgets and the Apple Watch app. All of the underlying work, the data sources and the original
design are Philipp's. This fork is not affiliated with or endorsed by him.
